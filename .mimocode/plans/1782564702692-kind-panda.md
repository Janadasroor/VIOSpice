# Plan: Update Shortcuts Dialog to Show All Shortcuts

## Goal
The `ShortcutsDialog` only discovers `QAction` shortcuts. It misses `QShortcut` objects and `keyPressEvent`-handled shortcuts. Update it to show a complete reference of all keyboard shortcuts.

## File to Modify
- `ui/shortcuts_dialog.cpp` — add static entries for non-QAction shortcuts

## Approach
Keep the existing dynamic discovery for QAction shortcuts, then append a hardcoded list of additional shortcuts that aren't QAction-based:

### Additional shortcuts to add:
```
/              Focus Component Search
Ctrl+R         Toggle Sticky Rotation (placement mode)
F2             Inline Rename (Project Explorer)
R              Rotate (during placement)
Shift+R        Rotate CCW (during placement)
H              Flip Horizontal (during placement)
Shift+V        Flip Vertical (during placement)
Space          Rotate Selected / Hand tool toggle
Delete         Delete Selected / Hovered Item
Escape         Cancel Placement / Deselect
```

### Implementation
After the dynamic QAction discovery loop, append these entries to the `shortcuts` map before sorting. This ensures they appear in the sorted table alongside the auto-discovered shortcuts.

## Verification
1. Build: `cmake --build build --target VioraEDA -j8`
2. Open app → Help menu → Keyboard Shortcuts
3. Verify all shortcuts appear, including `/`, `Ctrl+R`, `F2`, and placement-mode keys
4. Search filter should work for all entries
